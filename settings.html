Setup Guide

1. Create sprite folders — In your SillyTavern sprites directory, create a folder for each character (e.g., Alice, Bob). Place expression images inside (joy.png, sadness.png, etc.).

2. Add characters above — The name should match how the character appears in the narrative. The sprite folder defaults to the character name but can be customized.

3. Set aliases (optional) — Comma-separated alternate names, nicknames, or shortened forms. For example, if the character is "Elizabeth," you might add Liz, Beth, Lizzie. Japanese honorifics like -san, -chan, etc. are handled automatically.

4. Set pronouns — Helps the extension track characters through pronoun references like "she smiled" or "he turned away". Pronouns also carry across messages — if the last message detected Alice, and the next message opens with "She sighed," it resolves to Alice.

Detection signals (strongest → weakest):

Alice: speaker tag > Alice said attribution > Alice walked action > Alice's eyes possessive > She smiled pronoun > Alice bare mention > "Hello, Alice" vocative (in dialogue)

Slash commands:

/ss-focus Name — Manually switch to a character
/ss-detect — Test detection on the latest message
/ss-clear — Clear the sprite override
